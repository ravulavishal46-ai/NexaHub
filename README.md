# NexaHub

Smart Service Management Platform — users browse services, submit requests and track their
status; administrators manage services, users and requests from a secure dashboard.

**Stack:** Next.js · React · TypeScript · Tailwind CSS · Supabase (PostgreSQL + Auth) · Vercel
